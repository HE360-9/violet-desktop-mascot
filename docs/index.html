Violet Evergarden Desktop Mascot

基于 PyQt6 的桌面虚拟桌宠：大模型对话、本地中日双语语音合成、 离线语音输入、摄像头视觉与实时资讯，全部围绕「她」展开。

核心功能 Features

温柔、克制、会记得你说过的话。
💬

AI 人设对话

严格遵循薇尔莉特温柔内敛的人设，短句输出，可调节回复长度；遇到天气、热点、汇率问题自动调取实时数据。

🎙️

本地双语 TTS

/zh 中文、/ja 日语切换朗读，长文本自动分句，避开接口超时；基于 GPT-SoVITS，无云端语音费用。

⌨️

离线语音输入

按住空格说话、松开自动识别、ESC 取消，基于 Vosk 本地模型，全程不依赖联网语音接口。

📷

摄像头视觉

默认关闭；人脸与嘴部动作启发式检测，画面只在本机处理，不保存、不上传。

🌧️

天气感知人设

每 18 分钟后台查询天气，下雨自动切换病弱立绘，对话状态同步更新。

🧠

仿生记忆

短期印象会衰减，长期记忆只保存你明确留下的情感与事实；本地 JSON 存储，随对话按需召回。

快速开始 Quick Start

需要自行准备立绘、Vosk 模型与 GPT-SoVITS，详见仓库 README。
  1. 克隆仓库，创建 Python 3.11 / 3.12 虚拟环境
  2. 安装 requirements.txt 依赖
  3. 复制 config.env.example 为 config.env，填入自己的 API Key
  4. 把立绘放进 static/prep_png/，Vosk 模型放进 vosk-model/
  5. 运行 python main.py，或双击 Violet.exe
# 1. 获取代码
git clone https://github.com/HE360-9/violet-desktop-mascot.git
cd violet-desktop-mascot

# 2. 创建环境
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置并启动
Copy-Item config.env.example config.env
python main.py
